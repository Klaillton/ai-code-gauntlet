# Gauntlet app (skeleton)

Greenfield scaffold from **AI Code Gauntlet** — health-only, no business domain.

## Quick start

```bash
npm install
npm run prepare:browsers
npm run verify
npm run dev
```

## Next steps

1. Human writes/approves Gherkin under `features/`
2. Human approves OpenAPI changes under `openapi/`
3. Agent implements under `AGENTS.md` until `npm run verify` is green

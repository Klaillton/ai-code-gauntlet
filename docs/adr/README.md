# ADRs (Architecture Decision Records)

New kit/app ADRs live here. Use [`TEMPLATE.md`](./TEMPLATE.md).

Required sections (enforced by **D14** `adr-lint` on new/changed files in this tree):

- **Context**
- **Decision**
- **Consequences**
- **Discarded** (rejected alternatives + reason; non-empty)
- **Status** — `Accepted — YYYY-MM-DD` or `Superseded by ADR-XXXX — YYYY-MM-DD`

Do **not** delete superseded ADRs; only change Status. Legacy ADRs may still live as `docs/ADR-*.md` at the kit root (grandfathered; not under this glob).
